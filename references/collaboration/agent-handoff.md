# Agent handoff protocol

A handoff must stand alone without relying on chat history.

Include:

- repository/worktree;
- Jira ticket and contract hash;
- source/target branch and exact SHA;
- goal, acceptance criteria, scope, and non-goals;
- changed behavior/components;
- commands/checks and exact outcomes;
- unresolved findings and their dispositions;
- blockers, risks, limitations, and unverified items;
- authority already granted and external actions still requiring approval.

Do not include secrets, raw personal data, hidden reasoning, or enormous logs. A chat link without factual SHA-bound summary is insufficient.
